# Qwen3.5-27B Integration Design

**Date**: 2026-02-27  
**Status**: Approved

## Overview

Add support for Qwen3.5-27B multimodal model to VLMEvalKit by extending the existing Qwen3VLChat implementation with configurable thinking mode support.

## Background

Qwen3.5-27B is a 27B parameter vision-language model with:
- Native multimodal support (image, video, text)
- **Default thinking mode** - generates reasoning content in `\n...\\n\\n` format before final response
- Gated DeltaNet + sparse MoE architecture
- 262K native context length (up to 1M with YaRN)
- OpenAI-compatible API via vLLM/SGLang

### Key Differences from Qwen3-VL

| Feature | Qwen3-VL | Qwen3.5-27B |
|---------|----------|-------------|
| Thinking mode | Optional (CoT prompt) | **DEFAULT ON** |
| Disable thinking | N/A | `chat_template_kwargs: {enable_thinking: false}` |
| Sampling (thinking) | Standard | `temp=1.0, top_p=0.95, top_k=20, presence_penalty=1.5` |
| Sampling (non-thinking) | Standard | `temp=0.7, top_p=0.8, top_k=20, presence_penalty=1.5` |
| Max tokens (thinking) | 32K | **81,920** |
| Max tokens (non-thinking) | 32K | 32,768 |

## Design

### Approach: Extend Qwen3VLChat

Create `Qwen3_5VLChat` class inheriting from `Qwen3VLChat` with:
1. New `enable_thinking` parameter
2. Adjusted default sampling parameters based on mode
3. Support for `chat_template_kwargs` in vLLM calls

### Class Design

```python
class Qwen3_5VLChat(Qwen3VLChat):
    """Qwen3.5 model with configurable thinking mode."""
    
    INSTALL_REQ = False
    INTERLEAVE = True
    VIDEO_LLM = True

    def __init__(
        self,
        model_path: str,
        enable_thinking: bool = True,
        min_pixels: int | None = None,
        max_pixels: int | None = None,
        total_pixels: int | None = None,
        max_new_tokens: int = 32768,
        top_p: float = 0.8,
        top_k: int = 20,
        temperature: float = 0.7,
        repetition_penalty: float = 1.0,
        presence_penalty: float = 1.5,
        use_custom_prompt: bool = True,
        system_prompt: str | None = None,
        post_process: bool = False,
        verbose: bool = False,
        **kwargs,
    ) -> None:
        self.enable_thinking = enable_thinking
        
        # Adjust defaults for thinking mode
        if enable_thinking:
            temperature = 1.0
            top_p = 0.95
            max_new_tokens = max(max_new_tokens, 81920)
            presence_penalty = 1.5
        
        # Call parent with adjusted params
        super().__init__(
            model_path=model_path,
            min_pixels=min_pixels,
            max_pixels=max_pixels,
            total_pixels=total_pixels,
            max_new_tokens=max_new_tokens,
            top_p=top_p,
            top_k=top_k,
            temperature=temperature,
            repetition_penalty=repetition_penalty,
            presence_penalty=presence_penalty,
            use_custom_prompt=use_custom_prompt,
            system_prompt=system_prompt,
            post_process=post_process,
            verbose=verbose,
            **kwargs,
        )
```

### vLLM Integration

For thinking mode control in vLLM, pass `chat_template_kwargs`:

```python
def generate_inner_vllm(self, message, dataset=None):
    # ... existing code ...
    
    sampling_params = SamplingParams(
        temperature=self.temperature,
        max_tokens=self.max_new_tokens,
        top_p=self.top_p,
        top_k=self.top_k,
        repetition_penalty=self.repetition_penalty,
        presence_penalty=self.presence_penalty,
    )
    
    # Add thinking mode control
    extra_args = {}
    if not self.enable_thinking:
        extra_args['mm_processor_kwargs'] = {
            'chat_template_kwargs': {'enable_thinking': False}
        }
    
    # ... rest of implementation
```

### Config Registration

Add to `vlmeval/config.py`:

```python
qwen3_5vl_series = {
    "Qwen3.5-27B": partial(
        Qwen3_5VLChat,
        model_path="Qwen/Qwen3.5-27B",
        enable_thinking=True,
        use_vllm=True,
        temperature=1.0,
        top_p=0.95,
        top_k=20,
        max_new_tokens=81920,
        presence_penalty=1.5,
        repetition_penalty=1.0,

    "Qwen3.5-27B-NoThinking": partial(
        Qwen3_5VLChat,
        model_path="Qwen/Qwen3.5-27B",
        enable_thinking=False,
        use_vllm=True,
        temperature=0.7,
        top_p=0.8,
        top_k=20,
        max_new_tokens=32768,
        presence_penalty=1.5,
        repetition_penalty=1.0,
        tensor_parallel_size=8,
        gpu_memory_utilization=0.8,

    ),
}
```

Add `qwen3_5vl_series` to `model_groups` list.

## Usage

```bash
# With thinking mode (default)
python run.py --data MMBench_DEV_EN MME --model Qwen3.5-27B --verbose

# Without thinking mode (faster)
python run.py --data MMBench_DEV_EN MME --model Qwen3.5-27B-NoThinking --verbose
```
